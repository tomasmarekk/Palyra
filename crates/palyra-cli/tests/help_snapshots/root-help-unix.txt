Palyra operator CLI for secure local and remote runtime management.

Usage: palyra [OPTIONS] <COMMAND>

Commands:
  version         Show CLI build metadata
  setup           Bootstrap a Palyra installation [aliases: init]
  doctor          Run diagnostics, repair previews, and rollback workflows
  health          Run a narrow liveness/readiness probe across HTTP and gRPC gateway surfaces
  logs            Tail local gateway journal diagnostics
  status          Show transport and admin status across HTTP/gRPC surfaces
  acp             Run the ACP stdio bridge and legacy compatibility shim
  mcp             Manage MCP registry and run the stdio facade
  agent           Run one-off or interactive agent sessions
  agents          Manage daemon agent registry, bindings, and defaults
  routines        Manage unified automation routines across schedules and event triggers
  objectives      Manage durable objectives, heartbeats, standing orders, and programs
  flows           Inspect and control durable orchestration flows
  tasks           Inspect unified runtime tasks and WorkBoard items
  jobs            Inspect and control durable long-running tool jobs
  commitments     Extract, review, and schedule user commitments
  cron            Manage schedule-only cron workflows through the routines compatibility layer
  memory          Inspect and manage session, workspace, and learning memory
  message         Inspect and manage routed channel messages
  approvals       Review and resolve pending tool approvals
  sessions        List, inspect, and manage chat sessions
  tui             Launch the terminal operator client
  auth            Manage auth profiles, provider access, and OAuth/API-key flows
  channels        Manage connector channels and routing
  webhooks        Manage webhook-backed integrations
  docs            Discover local CLI help snapshots from source checkouts or portable installs
  plugins         Manage installed plugin packages and discovery
  hooks           Manage local hooks and bindings
  extension       Manage extension integration surfaces
  profile         Manage CLI connection profiles and active environment selection
  devices         List and manage paired operator devices
  node            Manage the local node runtime
  nodes           Inspect and invoke remote node RPC surfaces
  browser         Operate the browser service and browser-backed automation sessions
  system          Inspect runtime heartbeat, subsystem presence, operator insights, and recent system events
  state           Inspect and repair local durable state
  sandbox         Inspect effective process-runner and WASM sandbox policy surfaces
  completion      Generate shell completion scripts
  onboarding      Run guided onboarding workflows [aliases: onboard]
  deployment      Inspect deployment profiles, run preflights, and generate deploy recipes
  configure       Safely reconfigure an existing installation
  gateway         Gateway and runtime diagnostics surface [aliases: daemon]
  dashboard       Resolve or open the operator dashboard URL
  backup          Create or verify portable operator backups
  reset           Reset selected local runtime scopes
  uninstall       Remove an installed Palyra package and optional state
  update          Check or apply a packaged Palyra update
  support-bundle  Export, import, and replay support bundles
  policy          Explain policy decisions and authorization posture
  protocol        Validate schema and protocol contract artifacts
  eval            Create local eval bundles and replay metadata
  qa              Validate, preview, and execute QA Lab scenarios
  config          Inspect and validate local configuration
  workers         Inspect networked workers, leases, and cleanup evidence
  run             Wait for runs and export trajectories for audit and evals
  models          Inspect and configure model providers and defaults
  patch           Apply workspace patches through the guarded patch engine
  skills          Manage skill packages, trust, and lifecycle gates [aliases: skill]
  secrets         Manage local secrets and vault-backed credentials
  security        Run security audits and posture checks
  tunnel          Open an SSH tunnel for remote daemon access
  pairing         Manage device pairing and trust bootstrap

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global Options:
      --profile <PROFILE>
          Use the named CLI profile from the local profile registry

      --expect-profile <EXPECT_PROFILE>
          Require the resolved active profile name to match this value

      --config <CONFIG_PATH>
          Use this palyra.toml config file

      --state-root <STATE_ROOT>
          Use this runtime state root directory

  -v, --verbose...
          Increase logging verbosity (-v => debug, -vv => trace)

      --log-level <LOG_LEVEL>
          Set diagnostic log verbosity

          [default: info]
          [possible values: error, warn, info, debug, trace]

      --output-format <OUTPUT_FORMAT>
          Select text, JSON, or NDJSON output for automation

          [default: text]
          [possible values: text, json, ndjson]

      --plain
          Disable styled terminal output

      --no-color
          Disable ANSI color output

      --allow-profile-mismatch
          Allow commands to continue when the selected profile differs from context

      --allow-strict-profile-actions
          Permit strict profile-scoped actions after explicit profile checks

Examples:
  palyra setup --mode local
  palyra setup --deployment-profile single-vm --path ./config/palyra.toml
  palyra deployment profiles --json
  palyra acp --session-key ops:triage
  palyra docs search gateway
  palyra gateway status
  palyra dashboard --open
  palyra backup create --output ./artifacts/palyra-backup.zip
  palyra profile list --json
  palyra objectives list --kind heartbeat --json
  palyra system heartbeat
  palyra sandbox explain --runtime process-runner
  palyra update --check
  palyra --profile staging agents list --json
  palyra --profile prod --expect-profile prod gateway status
  palyra --profile prod --allow-strict-profile-actions reset --scope state --yes
  palyra --config ./palyra.toml --output-format json status --admin

Canonical command map:
  setup      Preferred bootstrap/init workflow (`init` remains as a compatibility alias)
  configure  Guided reconfiguration workflow for an existing installation
  acp        Preferred ACP stdio bridge entry point (`agent acp` remains compatible)
  docs       Local CLI help snapshot discovery surface
  gateway    Preferred runtime/admin family (`daemon` remains as a compatibility alias)
  dashboard  Thin operator shortcut for dashboard URL discovery/open workflows
  objectives Durable objective, heartbeat, standing-order, and program surface
  routines   Unified automation surface for schedules, hooks, webhooks, and system events
  backup     Portable lifecycle backup/create verification surface
  system     Runtime heartbeat, presence, and recent system-event observability
  sandbox    Effective isolation/runtime policy explain surface for process and WASM tooling
  plugins    Trusted WASM plugin binding and lifecycle surface
  hooks      Event-driven automation bindings over trusted plugins
  extension  Unified package preflight, grants, and lifecycle diagnostics
  reset      Destructive local recovery surface with explicit scope selection
  uninstall  Installer-aware package removal surface
  update     Package update/check orchestration surface
  onboarding Operator onboarding workflows (`onboard` stays as the shorthand alias)
  profile    First-class CLI profile lifecycle and environment selection
  qa         QA Lab scenario manifest validation
  webhooks   Webhook-backed integration management surface
