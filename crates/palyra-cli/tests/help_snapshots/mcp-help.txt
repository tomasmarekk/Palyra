Manage MCP registry and run the stdio facade

Usage: palyra mcp [OPTIONS] <COMMAND>

Commands:
  serve    Run the stdio MCP server
  list     List configured external MCP servers
  show     Show one configured external MCP server
  add      Add one external MCP server to local config
  set      Update one external MCP server in local config
  enable   Enable one external MCP server
  disable  Disable one external MCP server
  remove   Remove one external MCP server

Options:
  -h, --help
          Print help (see a summary with '-h')

Global Options:
      --profile <PROFILE>
          Use the named CLI profile from the local profile registry

      --expect-profile <EXPECT_PROFILE>
          Require the resolved active profile name to match this value

      --config <CONFIG_PATH>
          Use this palyra.toml config file

      --state-root <STATE_ROOT>
          Use this runtime state root directory

  -v, --verbose...
          Increase logging verbosity (-v => debug, -vv => trace)

      --log-level <LOG_LEVEL>
          Set diagnostic log verbosity

          [default: info]
          [possible values: error, warn, info, debug, trace]

      --output-format <OUTPUT_FORMAT>
          Select text, JSON, or NDJSON output for automation

          [default: text]
          [possible values: text, json, ndjson]

      --plain
          Disable styled terminal output

      --no-color
          Disable ANSI color output

      --allow-profile-mismatch
          Allow commands to continue when the selected profile differs from context

      --allow-strict-profile-actions
          Permit strict profile-scoped actions after explicit profile checks

Examples:
  palyra mcp list
  palyra mcp add docs --transport stdio --command mcp-docs --arg=--root --arg docs --namespace docs
  palyra mcp disable docs
  palyra mcp serve --read-only
  palyra mcp serve --session-key ops:triage
  palyra mcp serve --allow-sensitive-tools

Discoverability:
  `mcp add|set|enable|disable|remove` manages durable external MCP server declarations in palyra.toml.
  `mcp serve` exposes Palyra as a stdio MCP server facade over the same connection, access control, and approval model used by the rest of the CLI.
