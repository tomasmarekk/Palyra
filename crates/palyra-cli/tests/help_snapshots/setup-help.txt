Bootstrap a Palyra installation

Usage: palyra setup [OPTIONS]

Options:
      --mode <MODE>
          [default: local]
          [possible values: local, remote]

      --path <PATH>

      --force

      --tls-scaffold <TLS_SCAFFOLD>
          [default: bring-your-own]
          [possible values: none, bring-your-own, self-signed]

      --wizard

      --flow <FLOW>
          Select quickstart, manual, or remote onboarding

          [possible values: quickstart, manual, remote]

      --non-interactive
          Run without interactive prompts

      --accept-risk
          Accept the risk gates required by remote or public exposure

      --json
          Print the onboarding result as JSON

      --workspace-root <WORKSPACE_ROOT>
          Use this workspace root in generated configuration

      --auth-method <AUTH_METHOD>
          Choose how model-provider credentials are configured

          [possible values: chatgpt-login, api-key, anthropic-api-key, anthropic-oauth, minimax-api-key, minimax-api-key-global, minimax-api-key-cn, minimax-oauth-global, minimax-oauth-cn, xai-api-key, xai-device-code, xai-oauth, gemini-cli-oauth, google-gemini-api-key, openrouter-api-key, openrouter-oauth, skip, existing-config]

      --api-key-env <API_KEY_ENV>
          Read the model-provider API key from this environment variable name

      --api-key-stdin
          Read one model-provider API key from stdin; requires --non-interactive for scripted wizard runs

      --api-key-prompt
          Prompt securely for the model-provider API key

      --deployment-profile <DEPLOYMENT_PROFILE>
          Select the generated deployment profile

          [possible values: local, single-vm, worker-enabled]

      --bind-profile <BIND_PROFILE>
          Select loopback-only or public TLS gateway binding

          [possible values: loopback-only, public-tls]

      --daemon-port <DAEMON_PORT>
          Set the daemon HTTP port

      --grpc-port <GRPC_PORT>
          Set the daemon gRPC port

      --quic-port <QUIC_PORT>
          Set the daemon QUIC port

      --tls-cert-path <TLS_CERT_PATH>
          Use this TLS certificate path for public gateway binding

      --tls-key-path <TLS_KEY_PATH>
          Use this TLS private-key path for public gateway binding

      --remote-base-url <REMOTE_BASE_URL>
          Record this remote dashboard or gateway base URL

      --admin-token-env <ADMIN_TOKEN_ENV>
          Read the admin token from this environment variable name

      --admin-token-stdin
          Read one admin token from stdin; requires --non-interactive for scripted wizard runs

      --admin-token-prompt
          Prompt securely for the admin token

      --remote-verification <REMOTE_VERIFICATION>
          Choose how remote gateway identity is verified

          [possible values: none, server-cert, gateway-ca]

      --pinned-server-cert-sha256 <PINNED_SERVER_CERT_SHA256>
          Pin the remote server certificate SHA-256 digest

      --pinned-gateway-ca-sha256 <PINNED_GATEWAY_CA_SHA256>
          Pin the gateway CA SHA-256 digest

      --ssh-target <SSH_TARGET>
          Record the SSH target used for remote administration

      --skip-health
          Skip post-onboarding health checks

      --skip-channels
          Skip default channel setup

      --skip-skills
          Skip default skill bootstrap

  -h, --help
          Print help (see a summary with '-h')

Global Options:
      --profile <PROFILE>
          Use the named CLI profile from the local profile registry

      --expect-profile <EXPECT_PROFILE>
          Require the resolved active profile name to match this value

      --config <CONFIG_PATH>
          Use this palyra.toml config file

      --state-root <STATE_ROOT>
          Use this runtime state root directory

  -v, --verbose...
          Increase logging verbosity (-v => debug, -vv => trace)

      --log-level <LOG_LEVEL>
          Set diagnostic log verbosity

          [default: info]
          [possible values: error, warn, info, debug, trace]

      --output-format <OUTPUT_FORMAT>
          Select text, JSON, or NDJSON output for automation

          [default: text]
          [possible values: text, json, ndjson]

      --plain
          Disable styled terminal output

      --no-color
          Disable ANSI color output

      --allow-profile-mismatch
          Allow commands to continue when the selected profile differs from context

      --allow-strict-profile-actions
          Permit strict profile-scoped actions after explicit profile checks

Examples:
  palyra setup --mode local
  palyra setup --deployment-profile single-vm --path ./config/palyra.toml
  palyra setup --deployment-profile worker-enabled --wizard --non-interactive --accept-risk
  palyra setup --mode local --wizard
  palyra setup --mode remote --path ./config/palyra.toml --force

Discoverability:
  Use `palyra onboard wizard --flow quickstart` for the guided onboarding family.
  Use `palyra gateway status` after setup to verify runtime health.
